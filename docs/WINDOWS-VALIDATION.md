# Windows 实机验收

以下属于人工验收清单，并非当前 macOS 环境中已完成的测试。
建议使用 Windows 10 22H2 或 Windows 11、普通用户权限，先在非重要操作中体验。

## 启动与输入

- [ ] 双击 FoxCursor.exe，设置窗口显示，托盘有角色图标。
- [ ] 启用后原生系统指针替换为透明指针，角色跟随；点击圆点与真实落点一致。
- [ ] 在记事本、浏览器、Explorer 中测试单击、双击、右键菜单、选择文字、拖动窗口和滚轮；原应用收到原本输入。
- [ ] 在两块显示器间连续移动，包括副屏在左边 / 上边、100% + 150% / 200% 混合缩放；落点无偏移，不抢焦点。
- [ ] 运行中更改显示缩放或断开外接显示器，随后继续移动鼠标。
- [ ] 关闭设置窗口后仅驻留托盘；重复打开设置不会产生多个窗口。

## 动作

- [ ] 左键压扁、右键疑惑、双击跳跃、按住左键蓄力。
- [ ] 水平 / 垂直快速运动时叶子响应方向，静止后平滑归位。
- [ ] 开始文字输入后出现小键盘和敲击双手，停止约 650ms 后消失；只有修饰键时无夸张动作。
- [ ] 从 Explorer 文件列表或桌面拖文件，出现通用文件图标与抱持动作；释放或 Escape 后恢复。
- [ ] 对桌面框选、Explorer 空白处拖动检查是否误触发，并记录具体 Windows 版本（已知启发式限制）。
- [ ] 等待 8 秒，出现短暂待机动作，随后停止持续刷新；重新输入即中断。
- [ ] 关闭动画总开关，角色保持原图；位置继续跟随。

## 安全恢复（重要）

- [ ] Ctrl+Alt+F12：普通运行和打开设置/菜单时均恢复鼠标并退出两个进程。
- [ ] 单独结束 FoxCursor.exe（不要同时结束 Guardian），系统鼠标恢复。
- [ ] 暂停主进程线程超过 5 秒：Guardian 恢复鼠标，通知主进程并在必要时结束挂起进程。
- [ ] 单独结束 Guardian：主程序在下一次心跳检测时恢复鼠标并退出。
- [ ] 托盘“恢复系统鼠标”同时隐藏角色、释放 Hook，且不会自动重新隐藏鼠标。
- [ ] 托盘退出、锁屏、远程会话断开后系统鼠标恢复；解锁后需手动启用。
- [ ] 启动前先占用 Ctrl+Alt+F12 或移走 Guardian：程序拒绝隐藏鼠标，并给出提示。
- [ ] 运行 `scripts/restore-cursor.ps1` 可独立恢复当前用户保存的指针方案。
- [ ] 自定义 Windows 指针方案在退出后恢复；尝试运行期间更换方案，核对退出结果。

## 设置与性能

- [ ] 调整大小、透明度、Hotspot、偏移后，重启保持设置；删除/破坏设置 JSON 可回退默认值。
- [ ] 开机启动只修改当前用户 Run 项；关闭开机启动后该项移除。
- [ ] 任务管理器观察空闲、移动、持续输入的 CPU/GPU 和内存；记录硬件、显示器分辨率、缩放和刷新率。
- [ ] 退出后无残留 FoxCursor / Guardian 进程。重复启用/暂停至少 20 次检查句柄是否持续增长。

## 无副作用的真实 WPF 渲染检查

```powershell
$p = Start-Process .\artifacts\win-x64\FoxCursor.exe -ArgumentList '--render-preview', 'artifacts\preview' -Wait -PassThru
if ($p.ExitCode -ne 0) { throw 'WPF preview rendering failed' }
```

该模式绘制实际角色控件及设置窗口，生成 `character-states.png` 和 `settings-window.png`。
它不安装 Hook、不启动 Guardian、不隐藏系统指针。此模式验证素材与 WPF 绘制，不能替代上述真实输入和恢复测试。
